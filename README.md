# 🍽️ Website UMKM Kuliner

Repository ini berisi source code pengembangan website untuk salah satu UMKM di bidang kuliner. Proyek ini dibuat sebagai bagian dari tugas perkuliahan/sekolah dengan tujuan membantu UMKM memanfaatkan teknologi digital sebagai media informasi dan promosi usaha.

Website dirancang dengan memperhatikan karakteristik, identitas, dan kebutuhan UMKM yang menjadi objek pengembangan.

## 📌 Tentang Proyek

Website UMKM Kuliner merupakan website profil usaha yang dirancang untuk memperkenalkan bisnis kuliner kepada masyarakat secara digital.

Melalui website ini, pengunjung dapat mengetahui informasi mengenai usaha, melihat produk atau menu yang tersedia, menikmati galeri foto, serta melakukan pemesanan melalui WhatsApp.

Desain dan tampilan website akan disesuaikan dengan identitas visual serta karakteristik UMKM yang menjadi objek proyek.

## 🎯 Tujuan Pengembangan

1. Membantu UMKM memperkenalkan usaha melalui media digital.
2. Memperluas jangkauan promosi dan pemasaran produk.
3. Menyediakan informasi usaha dan produk secara terstruktur.
4. Mempermudah pelanggan dalam menghubungi dan melakukan pemesanan.
5. Menerapkan keterampilan pengembangan website menggunakan teknologi web dasar.

## ✨ Fitur Website

- **Beranda (Home)**  
  Menampilkan halaman utama sebagai pengenalan usaha dan informasi penting.

- **Tentang Kami (About Us)**  
  Menampilkan profil, sejarah singkat, dan informasi mengenai UMKM.

- **Daftar Menu / Produk**  
  Menampilkan berbagai produk atau menu yang ditawarkan beserta informasi pendukungnya.

- **Galeri Foto**  
  Menampilkan dokumentasi produk, tempat usaha, dan aktivitas UMKM.

- **Kontak dan Lokasi**  
  Menyediakan informasi kontak serta lokasi usaha agar mudah ditemukan pelanggan.

- **Pemesanan WhatsApp**  
  Memudahkan pelanggan melakukan pemesanan dengan mengarahkan mereka langsung ke WhatsApp UMKM.

## 🚀 Cara Menjalankan Website

1. Clone repository:

   ```bash
   git clone https://github.com/USERNAME/website-umkm-kuliner.git
   ```

2. Masuk ke direktori proyek:

   ```bash
   cd website-umkm-kuliner
   ```

3. Buka file `index.html` menggunakan browser.

Website juga dapat dijalankan menggunakan ekstensi Live Server pada Visual Studio Code.
